# Changelog

All notable changes to the NMRiH2 Loadouts application will be documented in this file.

## [0.1.0-alpha] - 2026-08-30

### Initial Public Alpha Release
- **Target Game Patch**: NMRiH2 `1.0.4.0` (Steam Build `24830003`).
- **Combat Optimizer**: Multiobjective state-space solver finding optimal attack sequences for unarmored and armored zombie archetypes.
- **Compare Matrix**: Interactive breakpoint comparison matrix across all melee weapons and firearms with active perk synchronization.
- **Builds & Responders**: Responder profile builder, perk leveling assistant, and loadout manager.
- **Confidence Indicators**: Clear dimension-specific confidence indicators (`Damage ✓`, `Stamina ✓`, `Timing ~Est`, `Armor Experimental`).
- **Feedback Diagnostics**: In-app `Report a Bad Result` modal generating structured scenario diagnostic bundles and one-click GitHub issues.
- **Offline Codec**: Compressed Base64URL share codes (`N2B1-`, `N2C1-`, `N2S1-`, `N2A1-`).
- **Zero Telemetry**: Client-side offline operation without external tracking.
